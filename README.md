## Featured Projects

### 🖥️ [Bitig](https://github.com/sametgurtuna/bitig) — Terminal Emulator for Windows
A Windows 11 terminal built from scratch on Electron, not a fork or a shell wrapper. Split panes, an inline suggestion engine ranked by frecency, a local-first AI companion (`Bitig Bilge`), parametric command runbooks, a sandboxed plugin system, and a Quake-style dropdown HUD.
`Electron` `TypeScript` `node-pty`

### 🧠 [SAM](https://github.com/sametgurtuna/SAM) — Smart Assistant Module
A fully local voice AI desktop companion. Controls your OS and answers queries with zero cloud dependency — fast, private, and deeply integrated into the system.
`Python` `Local AI` `Desktop`

### 🗺️ [KUT](https://github.com/sametgurtuna/KUT) — Operational Intelligence Platform
An event-driven platform that models real-world operations — organizations, teams, vehicles, incidents — on one live map. Real road routing, live dispatch simulation, compatibility-based recommendations, and a scrubbable event timeline.
`.NET 10` `React` `PostgreSQL` `SignalR`
