## About

I'm a Digital Game Design student at Halic University with about six years of programming experience, focused on building interactive experiences in Unity and Unreal Engine. My interest lies at the intersection of game feel, level design, and interactive storytelling — with a growing focus on how AI can shape gameplay.

Alongside game development, I build local-first software and developer tools, including **LocalMind**, a fully local AI assistant project.

- 📍 Based in Istanbul, Türkiye
- 🎓 Final-year student, Digital Game Design
- 🎮 Building game prototypes centered on mechanics and narrative
- 🧠 Developing LocalMind — local-first AI tooling
- 🦀 Currently learning Rust and shader programming
- 🤝 Open to studio internships, indie collaborations, and freelance work
