### About

I'm Samet, a Digital Game Design student at Halic University in Istanbul. I like building things from scratch rather than gluing frameworks together. Games are my main focus, mostly Unity and Unreal, but I spend just as much time writing full applications outside games: a terminal emulator, a local AI assistant, an operations platform. If a tool doesn't exist the way I want it, I build it myself.

Currently learning Rust and going deeper into shader programming. Open to studio internships, indie collabs and freelance work.

<br/>

### Featured Projects

**[Bitig](https://github.com/sametgurtuna/bitig)**  
A terminal emulator for Windows 11, built from scratch on Electron rather than forked from something else. Split panes, an inline suggestion engine, a local AI companion, parametric command runbooks, a sandboxed plugin system and a Quake style dropdown HUD.  
`Electron` `TypeScript` `node-pty`

**[SAM](https://github.com/sametgurtuna/SAM)**  
A fully local voice AI desktop companion that controls your OS and answers queries with zero cloud dependency. Fast, private and deeply integrated into the system.  
`Python` `Local AI` `Desktop`

**[KUT](https://github.com/sametgurtuna/KUT)**  
An event driven operational intelligence platform. Organizations, teams, vehicles and incidents live on one map with real road routing, live dispatch simulation and a scrubbable timeline you can rewind to any past moment.  
`.NET` `React` `PostgreSQL` `SignalR`

**[TurkiyemCLI](https://github.com/sametgurtuna/TurkiyemCLI)**  
A command line tool for quick info about Turkiye's cities, regions and stats, all without leaving the terminal.  
`JavaScript` `Node.js` `CLI`
